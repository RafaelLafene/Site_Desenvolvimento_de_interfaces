Repositório dedicado ao armazenamento e apresentação do projeto da disciplina de **Desenvolvimento de Interface** do curso de Análise e Desenvolvimento de Sistemas (ADS).

---

## 📌 Sobre o Projeto

Este projeto consiste na construção de uma interface web responsiva e interativa. O objetivo é aplicar na prática os conceitos fundamentais do desenvolvimento front-end, cobrindo desde a estruturação semântica do conteúdo e estilização visual até o desenvolvimento de algoritmos e manipulação dinâmica de elementos com JavaScript.

---

## 🚀 Tecnologias Utilizadas

* **HTML5:** Estruturação semântica e acessível das páginas web.
* **CSS3:** Estilização visual, layout (Flexbox/Grid) e responsividade.
* **JavaScript (ES6+):** Lógica de programação, manipulação do DOM e interatividade.
* **Git & GitHub:** Versionamento de código e hospedagem do repositório.
